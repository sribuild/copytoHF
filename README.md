A modern GUI based tool to quickly upload files to Hugging Face.
Please make sure you have the latest version of Python. 
This tool was built on Python 3.13 and updates may be limited.
This tool is free to use, edit, and redistribute.
Download dependences listed in requirements, then run the Python code file.
